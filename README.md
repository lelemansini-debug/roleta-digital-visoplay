# Roleta Digital Viso Play

Projeto inicial de roleta digital para totem touchscreen, offline, personalizavel por cliente e preparado para futura camada Android com Capacitor.

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Personalizacao

Edite `src/config/clientConfig.js` para trocar cliente, cores, artes, textos, premios, pesos e tempo de giro.

Os assets da demo ficam em `src/assets/clients/demo/`.
